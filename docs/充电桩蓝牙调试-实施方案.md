# 充电桩蓝牙调试 — 实施方案

> 版本：v1.0  
> 日期：2026-06-02  
> 目标：在 **同一套 uni-app 代码** 下，兼容 **Android/iOS App** 与 **微信小程序**，复用 `iestool_v002/charging_monitor` 的 **JSON v2.0 通信协议**，实现充电桩蓝牙调试上位机功能。

---

## 1. 背景与参考

### 1.1 现有上位机（Qt）

| 项目 | 说明 |
|------|------|
| 路径 | `iestool_v002/charging_monitor/` |
| 传输层 | **TCP**（默认 `192.168.1.100:9699`） |
| 协议层 | `chargingprotocol.h/.cpp` — JSON v2.0 |
| 业务层 | `chargingmonitor.cpp` — 多 Tab 界面与命令分发 |
| 收发解析 | `tcpclient.cpp` — 粘包处理、按行/按 JSON 对象拆帧 |

Qt 版 **不含蓝牙代码**；移动端将 **协议与业务逻辑 1:1 移植**，仅把 `TcpClient` 替换为 **BLE 传输层**（App 可选保留 TCP 作为 WiFi 调试通道）。

### 1.2 现有 miniapp 入口

- 页面：`miniapp/pages/toolbox/charger-bluetooth/charger-bluetooth.vue`（占位）
- 权限：工具箱 **L3+**（与运维平台同级）
- `manifest.json` 已声明 App 端 `Bluetooth` 模块

## 2. 总体目标

| 功能域 | 说明 |
|--------|------|
| 连接管理 | BLE 扫描、连接、断开、重连；连接状态与信号强度 |
| 充电实时监控 | 系统信息 + 多枪运行数据（电压/电流/SOC/电量/费用/时长等） |
| 启停控制 | 按枪号启动/停止充电 |
| 系统参数 | 查询/修改多类参数；参数初始化、系统重启 |
| 故障信息 | 故障列表弹窗 |
| 日志与存储 | 远程文件列表/查看/下载；历史记录（故障/充电/刷卡）查询与清除 |
| 通信调试 | 收发 JSON 日志、自定义 JSON 发送 |
| 固件升级 | 分片上传（二期，Payload 较大需重点测 MTU） |

## 3. 双端兼容策略（一份代码）

### 3.1 分层架构

```
┌─────────────────────────────────────────────────────────┐
│  pages/charger/*  UI 页面（Vue3，条件编译仅用于布局差异）   │
├─────────────────────────────────────────────────────────┤
│  composables/useChargerSession.js  会话/心跳/状态/store   │
├─────────────────────────────────────────────────────────┤
│  services/charger/dispatcher.js   命令分发（对齐 Qt 槽函数）│
├─────────────────────────────────────────────────────────┤
│  services/charger/protocol.js     协议常量 + 构包/解包     │  ← 100% 共用
│  services/charger/json-framer.js    粘包/拆 JSON 帧        │  ← 100% 共用
├─────────────────────────────────────────────────────────┤
│  services/charger/transport/                             │
│    ├── index.js          工厂：createTransport(type)      │
│    ├── ble-transport.js  BLE 读写/notify（主通道）         │
│    └── tcp-transport.js  TCP Socket（App 可选，对齐 Qt）   │
└─────────────────────────────────────────────────────────┘
```

**原则**：UI 与协议 **不区分平台**；差异收敛在 `transport` 与少量 `#ifdef` 权限引导。

### 3.2 App vs 微信小程序差异

| 能力 | App (app-plus) | 微信小程序 (MP-WEIXIN) |
|------|----------------|------------------------|
| BLE 扫描/连接 | `uni.*Bluetooth*` 全量 API | 同左，需用户授权蓝牙 |
| 后台保活 | 相对宽松 | 切后台易断连，需重连提示 |
| TCP 局域网 | **可选**（`plus.socket` / uni TCP） | 生产环境难连任意 IP，**不做默认** |
| 保存文件/相册 | 本地文件系统 | `wx.getFileSystemManager` + 用户目录 |
| 固件大文件上传 | 可行 | MTU 小、耗时长，二期验证 |

### 3.3 条件编译约定

```javascript
// transport/index.js
// #ifdef APP-PLUS
export { createTcpTransport } from './tcp-transport.js'
// #endif
export { createBleTransport } from './ble-transport.js'

export function createTransport(mode) {
  // #ifdef APP-PLUS
  if (mode === 'tcp') return createTcpTransport()
  // #endif
  return createBleTransport()
}
```

小程序端连接页 **仅展示 BLE**；App 连接页提供 Tab：**蓝牙 / WiFi(TCP)**。

## 4. 通信协议（完全复用 v2.0）

> 源码对照：`iestool_v002/charging_monitor/chargingprotocol.h`

### 4.1 报文 envelope

每条消息均为 JSON 对象：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `version` | string | 是 | 固定 `"2.0"` |
| `timestamp` | string | 是 | `yyyy-MM-dd HH:mm:ss.zzz` |
| `command` | string | 是 | 命令名 |
| `data` | object | 是 | 载荷 |
| `status` | int | 否 | 响应状态码 |

### 4.2 命令一览

| command | 方向 | 用途 |
|---------|------|------|
| `Heartbeat` | 客户端→设备 | 心跳，连接后 10s 周期 |
| `SystemInfo` | 设备→客户端 | 型号、枪数、功率、网络、故障数、版本 |
| `GunInfo` | 设备→客户端 | 单枪实时数据（可多次推送） |
| `ChargeControl` | 客户端→设备 | `gunNumber` + `action`（0 停 / 1 启） |
| `ParamQuery` | 客户端→设备 | `type`: Basic/Network/Meter/Enable/Fee/SDK/QRCode |
| `ParamModify` | 客户端→设备 | `type` + `params[]` |
| `FaultInfo` | 客户端→设备 | 故障列表查询 |
| `HistoryOperations` | 双向 | `subCommand`: Query/Clear + `historyType` |
| `FileOperations` | 双向 | `subCommand`: Query/View/Download/Delete/Upload |
| `FirmwareUpgrade` | 双向 | 分片 Base64 + CRC |
| `CustomData` | 客户端→设备 | 扩展：`reboot`、`paramInit` 等 |

### 4.3 状态码

| 值 | 含义 |
|----|------|
| 0 | 成功 |
| 1 | 错误 |
| 2 | 无效命令 |
| 3 | 参数错误 |
| 4 | 设备忙 |
| 5 | 未连接 |
| 6 | 枪未找到 |

### 4.4 帧边界（粘包处理）

Qt `tcpclient.cpp` 逻辑移植到 `json-framer.js`：

1. 优先按 **`\r\n` 行分隔** 拆包；
2. 否则按 **花括号配对** 提取完整 JSON；
3. 缓冲区超时 5s 清空（防脏数据）。

**BLE 发送**：Compact JSON UTF-8；若单包超过 MTU，在 `ble-transport.js` 内按 **20/512 字节** 分片写入同一 characteristic（需与固件确认是否需长度头）。

**BLE 接收**：notify 回调累积字节 → 交给 `json-framer` → 得到完整对象 → `dispatcher`。

### 4.5 关键报文示例

**心跳（连接后立即发，之后每 10s）**

```json
{
  "version": "2.0",
  "timestamp": "2026-06-02 12:00:00.000",
  "command": "Heartbeat",
  "data": { "sequence": 1, "time": "2026-06-02 12:00:00.000" }
}
```

**充电控制**

```json
{
  "version": "2.0",
  "timestamp": "2026-06-02 12:00:00.000",
  "command": "ChargeControl",
  "data": { "gunNumber": 1, "action": 1 }
}
```

**历史查询**

```json
{
  "version": "2.0",
  "timestamp": "2026-06-02 12:00:00.000",
  "command": "HistoryOperations",
  "data": {
    "subCommand": "Query",
    "historyType": "fault",
    "startIndex": 0,
    "fetchCount": 10,
    "queryId": 1
  }
}
```

## 5. BLE 连接流程（移动端）

> **待硬件确认**：Service UUID、Write UUID、Notify UUID、设备广播名前缀。

```
用户打开「充电桩蓝牙调试」
    │
    ▼
openBluetoothAdapter（失败则引导开启系统蓝牙）
    │
    ▼
startBluetoothDevicesDiscovery（可按 name 过滤，如 "CCU"/"IES"）
    │
    ▼
用户选择设备 → createBLEConnection
    │
    ▼
getBLEDeviceServices → getBLEDeviceCharacteristics
    │
    ▼
enable notify(RX) + 记录 write(TX) characteristicId
    │
    ▼
发送 Heartbeat → 启动 10s 定时器
    │
    ▼
onBLECharacteristicValueChange → json-framer → dispatcher
    │
    ▼
断开 / 错误 → 停止心跳 → 提示重连
```

**需写入 `manifest.json` / 小程序后台**：

- App：`Bluetooth` 模块（已有）、Android 蓝牙与定位权限说明
- 微信小程序：在公众平台配置 **蓝牙** 相关隐私接口；`app.json`/`manifest` 声明 `scope.bluetooth`

## 6. 页面与功能映射（Qt Tab → uni-app）

### 6.1 路由规划

采用 **主壳 + 子页**（小程序单页不宜堆 7 个 Tab，用底部或分段导航）：

```
pages/toolbox/charger-bluetooth/charger-bluetooth.vue  # 功能导航首页
pages/toolbox/charger-connect/connect.vue              # 蓝牙连接
pages/toolbox/charger-monitor/monitor.vue              # 充电监控
pages/toolbox/charger-ble-debug/ble-debug.vue          # 蓝牙收发调试
```

> 微信小程序要求「一页一目录」（`path/同名.vue`），不可在同一目录下放多个页面文件，否则会触发代码依赖分析忽略错误。

`pages.json` 使用 **subpackage** `charger` 分包，避免主包过大。

### 6.2 界面对照

| Qt 模块 | uni-app 页面 | 核心交互 |
|---------|--------------|----------|
| 充电数据监控 | `monitor.vue` | SystemInfo 卡片；Gun 列表（最多 20 枪）；启动/停止；故障数点击→Fault 弹窗 |
| 系统参数交互 | `params.vue` | 参数类型 Picker；表格 name/type/value/desc；查询/保存；参数初始化、重启 |
| 文件操作 | `files.vue` | 路径 `/log` 列表；查看/下载；历史 fault/charging/card 分页 |
| 数据内容交互 | `comm-log.vue` | TX/RX 时间戳日志；清空；导出（App 写文件 / 小程序复制） |
| 自定义数据 | `comm-log.vue` 子 Tab | 预设 JSON + 手动发送 |
| 固件升级 | `firmware.vue` | 选文件→分片→进度条（二期） |
| FaultInfoDialog | `components/charger/FaultPanel.vue` | 弹层表格 |
| FileViewerDialog | `files.vue` 内 | 分片下载合并展示 |

推荐使用 **Composable + reactive**（与现有 miniapp 风格一致）：


全局单例会话：避免多页面重复连接。

## 9. 权限、配置与安全

| 项 | 说明 |
|----|------|
| 工具箱 L3+ | 保持与 `permission.js` / 服务端一致 |
| 蓝牙隐私 | 小程序需用户授权；首次进入连接页说明用途 |
| 操作确认 | 启停充电、重启、清历史、改参数 **二次确认** |
| 通信日志 | 默认内存限制 500 条，防小程序内存溢出 |
| 固件/文件 | 大 payload 仅在 WiFi/良好 BLE 下允许；显示进度与取消 |

**manifest 补充（实施时写入）**：

```json
"mp-weixin": {
  "__usePrivacyCheck__": true
}
```

> 说明：`requiredPrivateInfos` **仅用于位置类接口**（如 `getLocation`），**不能**填写蓝牙 API。蓝牙需在 [微信公众平台 → 用户隐私保护指引](https://mp.weixin.qq.com/) 中声明「蓝牙」用途，并在连接页引导用户授权。

Android App `AndroidManifest` 通过 HBuilderX 可视化配置蓝牙、定位（Android 12+ 扫描 BLE 常需）。

## 11. 风险与待确认项

| 编号 | 问题 | 影响 | 建议 |
|------|------|------|------|
| R1 | BLE Service/Characteristic UUID | 无法通信 | **实施前向硬件组索取** |
| R2 | BLE 上 JSON 是否带 `\r\n` | 拆帧逻辑 | 用示波/日志与 Qt TCP 对比 |
| R3 | 单包最大长度 / 是否需长度前缀 | 写特征失败 | 与固件联调 MTU 协商 |
| R4 | 小程序后台蓝牙限制 | 调试中断 | UI 明确「请保持前台」 |
| R5 | GunInfo 状态枚举两套 | UI 文案 | 以 `chargingmonitor.cpp` 实际映射为准 |
