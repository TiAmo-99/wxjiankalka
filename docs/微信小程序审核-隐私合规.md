# 微信小程序审核 — 隐私合规说明

## 审核拒绝原因（3.4）

注册环节收集用户信息（手机号、昵称等），需在小程序内提供 **《用户服务协议》** 与 **《隐私政策》**，并在用户 **明示同意** 后方可注册。

## 代码侧已完成的改动

| 项 | 路径 |
|----|------|
| 隐私政策页 | `pages/legal/privacy/index` |
| 用户服务协议页 | `pages/legal/user-agreement/index` |
| 注册页勾选同意 | `pages/register/register` |
| 我的页底部入口 | 隐私政策 · 用户服务协议 |
| 首次打开提示 | `App.vue`（仅微信小程序） |

## 提审前请在微信公众平台配置

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 小程序  
2. **设置** → **基本设置** → **服务内容声明** → **用户隐私保护指引**  
   - 填写收集的信息类型：手机号、昵称、选填姓名/邮箱、微信 openid（登录）、学习记录等  
   - 用途：账号注册登录、学习数据同步、邮件提醒（可选）  
   - 说明协议在小程序内查看：**我的** 页底部 / **注册** 页链接  
3. **设置** → **基本设置** → 如要求填写隐私政策链接，可填官网或说明「见小程序内 pages/legal/privacy 页面」（以平台表单为准）  
4. 重新上传代码，版本说明中注明：**已补充用户协议与隐私政策，注册前需勾选同意**
