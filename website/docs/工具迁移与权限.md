# 工具迁移与权限对照

小程序工具箱入口：`miniapp/pages/toolbox/toolbox.vue`  
权限逻辑：`miniapp/utils/permission.js`（与后端 `permissionService` 等级一致）

---

## 1. 权限等级

| 等级 | 标签（小程序） | 能力 |
|------|----------------|------|
| L0 | 普通学员 | 计算器 |
| L1+ | `perm_level > 0` | 二维码 |
| L3+ | `perm_level > 2` | 工具箱：充电桩蓝牙、运维平台 |
| L10 | 最终管理员 | 小程序内审核他人权限申请 |

常量（小程序）：

```js
QRCODE_MIN_LEVEL = 1   // canUseQrcode: permLevel > 0
TOOLBOX_MIN_LEVEL = 3  // canUseToolbox: permLevel > 2
FINAL_ADMIN_LEVEL = 10
```

后端二维码接口：`server/src/routes/tools.js` 调用 `permissionService.canUseQrcode`。

## 2. 工具迁移矩阵

| 工具 | 小程序路径 | 官网路径（规划） | API / 依赖 | 官网首期 |
|------|------------|------------------|------------|----------|
| 计算器 | `/pages/toolbox/calculator/calculator` | `/app/tools/calculator` | 无（纯前端） | ✅ 建议 |
| 二维码 | `/pages/toolbox/qrcode/qrcode` | `/app/tools/qrcode` | `POST /tools/qrcode` | ✅ 建议 |
| 充电桩蓝牙 | `/pages/toolbox/charger-bluetooth/*` | — | BLE + `services/charger/*` | ❌ 文档+小程序码 |

| 充电监控 | `charger-monitor/monitor` | — | 同上 | ❌ |
| 运维平台 | `/pages/toolbox/ops-platform/ops-platform` | `/app/tools/ops` | `https://cms.iesztn.com` | ⏳ 需代理 |

## 3. 各工具说明

### 3.1 计算器

- 逻辑：`miniapp/utils/calculator.js`
- 迁移：复制为 `website` 内纯 TS/JS 模块，无登录也可公开；若与小程序一致可仍要求 L0（登录即可）。

### 3.2 二维码

- **生成**：调用 `POST /tools/qrcode`，body `{ text, size }`，返回 base64 PNG（见 `qrcodeService.js`）。
- **扫码**：小程序用 `uni.scanCode`；Web 可用 `html5-qrcode` 等，需 HTTPS 与相机权限；权限 L1+ 与小程序对齐。

### 3.3 充电桩蓝牙

- 协议与分层见 [充电桩蓝牙调试-实施方案.md](../../docs/充电桩蓝牙调试-实施方案.md)。
- 传输：`miniapp/services/charger/ble-transport.js`（微信 BLE API）。
- Web：仅部分浏览器支持 Web Bluetooth，且无法覆盖微信小程序场景；**官网首期不实现**，产品页链到小程序。

### 3.4 运维平台

- 配置：`miniapp/config/ops-platform.js`

```js
baseUrl: 'https://cms.iesztn.com'
// getstationlist, getterminallist, getDebugCp
```

- 小程序通过 `miniapp/utils/ops-request.js` 直连。
- **官网建议**：在 `server` 增加代理路由，校验 JWT + `perm_level > 2`，密钥放 `.env`，避免 CORS 与密钥泄露。

---

## 4. 官网 UI 行为（与小程序对齐）

1. 进入 `/app/tools` 时 `GET /auth/me` 读取 `permLevel`。
2. 卡片展示锁标「L1+」「L3+」；点击时若权限不足，弹窗引导「权限申请」→ `/app/permission`。
3. 提交申请：`POST /auth/permission-requests`（字段与小程序 `permission-apply` 页一致）。

---

## 5. 代码复用建议

| 来源 | 可复用方式 |
|------|------------|
| `calculator.js` | 复制到 `website/src/lib/` |
| `permission.js` | 复制等级判断函数（去掉 `uni.showModal`，改为 Web UI） |
| `request.js` | 参考逻辑新建 `fetch` 封装 |
| `charger/*` | 不迁 Web；仅文档引用协议版本 v2.0 |
| `ops-request.js` | 二期经服务端代理后再封装 |

---

## 6. 产品页与工具关联

产品 JSON 可增加 `relatedTools` 字段，例如：

- `calculator` → 全员或登录可用
- `qrcode` → L1+
- `charger-ble` → 跳转小程序
- `ops-platform` → L3+ Web 或小程序

详见 [个人官网-设计方案.md](./个人官网-设计方案.md#6-充电桩营销内容模型建议)。
