# www.jiankalka.cn 个人官网 — 设计方案

> 版本：v1.1  
> 日期：2026-06-04  

**建设路线**：官网可完全独立开发，见 [独立站-架构与开发思路.md](./独立站-架构与开发思路.md)。下文「对接 server / 小程序」为**可选方案 B**。

---

## 1. 定位与目标

| 维度 | 说明 |
|------|------|
| **主站** `www.jiankalka.cn` | 充电桩/充电设备**产品营销**、方案、案例、下载与联系；个人/品牌展示 |
| **API** `server.jiankalka.cn` | 继续承载账号、权限、工具类接口；不把营销页塞进 Node `/admin` 静态目录 |
| **微信小程序** | 考研学习记录 + 工具箱（含充电桩蓝牙调试）；官网负责**引流与说明**，工具分流「网页版 / 小程序版」 |
| **登录** | 官网使用**手机号 + 密码**，复用 `POST /auth/phone-login`，与小程序/App 同一 `users` 表与 JWT |

营销与 API 解耦，与 [deploy.md](../../docs/deploy.md) 中「主站 www 可另做官网」一致。

## 2. 现有资产盘点

### 2.1 可直接对接 www

| 能力 | 说明 |
|------|------|
| 认证 | `phone-login` / `phone-register` / `set-initial-password` / `auth/me` / `PATCH /me` |
| 权限 | `users.perm_level`（L0 计算器 … L3+ 工具箱 … L10 审核） |
| 工具 API | `POST /tools/qrcode`（L1+，返回 PNG base64） |
| 规范 | [api-convention.md](../../docs/api-convention.md) — Bearer JWT、统一 `code` |

### 2.2 主要在小程序端、官网需区别对待

| 模块 | 路径/说明 | 官网策略 |
|------|-----------|----------|
| 计算器 | `miniapp/utils/calculator.js` | 纯前端，易迁 Web |
| 二维码 | 小程序扫码 + `POST /tools/qrcode` | Web 做「生成」；扫码依赖相机 API |
| 充电桩 BLE | `miniapp/services/charger/*` | 依赖微信/App BLE；官网首期仅说明 + 小程序码 |
| 运维平台 | `miniapp/config/ops-platform.js` → `cms.iesztn.com` | 需评估服务端代理与密钥 |
| 考研业务 | 计划/上报/词库 | 非营销主路径；页脚链到小程序即可 |

## 3. 总体架构

```
用户浏览器 / 微信
        │
        ├─► www.jiankalka.cn (443)     ← 宝塔独立站点，静态或 SSR
        │         │
        │         └─► 可选：/api/ 反代 ──┐
        │                              │
        ├─► 微信小程序 ─────────────────┤
        │                              ▼
        └─► server.jiankalka.cn (443)  ← Express :3000
                    ├─ /api/v1/*
                    ├─ /admin/*
                    └─► MySQL (wxjiankalka)
```

**原则**

- `website/` 为独立前端工程，构建产物部署到 `www` 站点根目录。
- `server/` 仅做 CORS/反代相关小改动，不把营销 HTML 放入 `server/public`。
- 账号统一：`role=student` + `perm_level`，与小程序一致。

## 4. 站点信息架构（IA）

### 4.1 公开区（无需登录）

| 路径 | 内容 |
|------|------|
| `/` | 首页：品牌、slogan、产品矩阵、CTA |
| `/products` | 产品列表与详情 |
| `/solutions` | 应用场景方案 |
| `/cases` | 案例（可先 Markdown/JSON 驱动） |
| `/about` | 简介、联系方式 |
| `/download` | 小程序码、资料下载 |
| `/legal/privacy` | 隐私政策（与小程序 legal 同源文案） |
| `/legal/terms` | 用户协议 |

### 4.2 会员区（登录后 `/app/*`）

| 路径 | 说明 | 权限 |
|------|------|------|
| `/app` | 控制台：昵称、等级、快捷入口 | 登录 |
| `/app/tools` | 工具箱（对齐小程序 toolbox） | 按 L 显示 |
| `/app/tools/calculator` | 计算器 | L0 |
| `/app/tools/qrcode` | 二维码生成 | L1+ |
| `/app/tools/ops` | 运维查询 | L3+ |
| `/app/profile` | 资料、改密 | 登录 |
| `/app/permission` | 权限申请 | 登录 |

### 4.3 首期不做

- 充电桩蓝牙完整上位机（保留小程序/App；官网放说明 + 小程序码）。
- 考研学习计划全功能 H5（避免主次颠倒）。

### 4.4 顶栏导航

```
[Logo]  产品  方案  案例  工具  关于  [登录 / 用户▼]
```

「工具」→ `/app/tools`；未登录跳转 `/login?redirect=...`。

## 5. 登录与会话

### 5.1 首期：手机号 + 密码

```http
POST https://server.jiankalka.cn/api/v1/auth/phone-login
{ "phone": "13800138000", "password": "******" }
```

成功后请求头：`Authorization: Bearer <token>`，拉取 `GET /auth/me`。

注册：`POST /auth/phone-register`（受 `ALLOW_SELF_REGISTER` 控制）。  
微信注册未设密：`POST /auth/set-initial-password`。  
改密：`PATCH /auth/password`（已登录）。

注册/登录页须勾选隐私协议（参考 `miniapp/components/LegalAgreeBar.vue`）。

### 5.2 Token 存储

| 部署方式 | 建议 |
|----------|------|
| www 反代 `/api/`（同源） | `httpOnly` Cookie（更安全） |
| 前端直连 `server` 子域 | `localStorage` + 严格 CORS；注意 XSS |

### 5.3 二期可选

- 微信网站应用扫码登录（需 openid/unionid 绑定）。
- 短信验证码（需新增 SMS，非必需）。

## 7. 技术选型建议

| 层级 | 建议 | 理由 |
|------|------|------|
| 框架 | Nuxt 3 或 Vite + Vue 3 | 与 `admin-web`、miniapp 栈一致 |
| 样式 | Tailwind 或 SCSS | 营销页视觉灵活 |
| 内容 | Markdown / JSON | 产品页易维护 |
| 部署 | 宝塔 `www` 站点 | 与 API PM2 进程独立 |
| SEO | Nuxt SSG/SSR 或预渲染 | 产品关键词 |

**规划目录**（阶段一初始化）：

```
website/
├── README.md
├── docs/                 # 本文档目录
├── content/              # 产品、案例 Markdown/JSON
├── public/               # 静态图
└── src/                  # 页面、组件、api 封装
```

## 8. 后端配合项（最小集）

| 项 | 优先级 | 说明 |
|----|--------|------|
| CORS 白名单 | P0 | 允许 `https://www.jiankalka.cn` |
| `WEBSITE_BASE_URL` | P1 | 邮件/通知中的官网链接 |
| 运维 API 代理 | P1 | 若做 Web 运维；密钥仅服务端 |

| 微信网站登录 | P3 | 非首期 |

无需新建用户表。

## 9. 品牌与双业务呈现

小程序 Tab 以**考研学习**为主、**工具箱**（含充电桩）为辅。官网以充电营销为主时：

- 首页视觉与文案主打充电产品/调试能力。
- 页脚提供「考研学习记录小程序」入口。
- 避免用户误以为官网主要是考研产品。

---

## 10. 安全与合规

- 全站 HTTPS；JWT 勿放在 URL query。
- 登录防暴力：Nginx `limit_req` 或中间件（后期）。
- 隐私/用户协议与小程序 legal 页面**同源文案**。
- 运维代理不得把第三方密钥打进前端 bundle。
- 联系表单若收集个人信息，在隐私政策中说明用途与留存期。

## 11. 分阶段实施路线

### 阶段一（1–2 周）

- 初始化 `website/` 前端工程。
- 首页、产品、关于、legal 页。
- `/login`、`/register`、`/app` 个人中心。
- 宝塔部署 `www`，CORS 或 `/api` 反代调通。

### 阶段二（约 1 周）

- Web 计算器、二维码生成（`/tools/qrcode`）。
- 权限不足提示 + 权限申请页。

### 阶段三（按需）

- 运维查询（服务端代理第三方 API）。
- 案例 CMS、联系表单/邮件 webhook。

### 阶段四（可选）

- 微信网站登录、unionid 与手机号绑定。
